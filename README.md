## Descripción del repositorio

Este repositorio tiene como propósito almacenar, organizar y documentar las diferentes prácticas y actividades realizadas durante la materia de **Estructura de Datos**.

Aquí se guardarán los programas, ejercicios y proyectos desarrollados a lo largo del curso, principalmente utilizando el lenguaje de programación **C++**.

Cada actividad estará acompañada de commits descriptivos para mantener un registro claro y ordenado de los cambios, avances y conocimientos aplicados durante cada nivel de desarrollo.
